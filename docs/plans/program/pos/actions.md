# Action contracts — every visible POS action

Format: **Action** (screens) · role/permission · preconditions · inputs · validation · loading/disabled · command (existing module or task) · persisted effects · success destination · failure/retry · evidence.
State dimensions stay separate: payment · refund · booking/resource commitment · preparation · attendance · entitlement · talent settlement. Labels are outcome-specific ("Collect $890", "Issue 2 tickets", "Cancel booking").
