# Add Gallery Freeform Marathon — Screenshot Matrix

Marathon converts Sections/Connected items from black-box `section_embed` inserts into editable freeform layer groups.

## Baseline (pre-marathon polish)

See sibling folder [`../add-gallery-polish/`](../add-gallery-polish/) for panel navigation, drag badges, and first proof-batch sections.

## Marathon capture checklist

For each row, capture: Page Structure tree + canvas with Title selected + parent section inspector.

| Category | Section / item | Template ID | Layers to verify |
|----------|----------------|-------------|------------------|
| Hero | Hero Split | `hero-split` | Title, Background Image, Primary Button |
| Hero | Hero Minimal | `hero-minimal` | Title, Primary Button |
| About | About Simple | `about` | Intro Text, Title, Description |
