# test-quarantine.txt — files excluded from the recursive builder/site-admin
# test lanes in package.json. Applied by `scripts/list-test-files.cjs`, which is
# the single expansion used BOTH by the npm lanes and by
# `check:builder-test-lane-coverage` — so a quarantined file is dropped from the
# lane AND exempted from the coverage guard in one place, and the two can never
# disagree.
#
# WHY THIS FILE EXISTS: the lanes used to be hardcoded file lists, so a new test
# file silently never ran in CI (W0-B, 2026-07-09). Converting them to globs
# surfaced ~90 orphaned test files; 4 of them failed and were parked here.
#
# STATUS 2026-08-04 (fix #6 / B2): THE QUARANTINE IS EMPTY. All four entries
# were resolved rather than re-parked:
#   • builder-node/style-token-bindings.test.ts — the TEST was wrong, not the
#     catalog: `tokens/registry.ts` documents `defaultValue: ""` as the
#     deliberate "follow the active background mode" sentinel, so asserting a
#     hex fallback on EVERY color token contradicted the shipped design (and
#     pinning one would force dark-mode tenants onto a white canvas).
#     Re-pointed at the real invariant: hex OR the empty inherit sentinel.
#   • site-admin-m1.test.ts / site-admin-m5.test.ts — fixture rot. Locale
#     validation moved from a hardcoded ['en','es'] membership gate to BCP-47
#     SHAPE validation (membership now lives in the `app_locales` registry), and
#     HOMEPAGE_SLOT_KEYS is DERIVED from the homepage template meta (4 slots →
#     12 after M7.1). Both now assert the contract that actually holds.
#   • edit-chrome/inspectors/responsive-field-state.test.ts — not broken, just
#     in the wrong runner's tree: it is vitest-authored and `tsx --test` cannot
#     require the vitest package. MOVED to
#     `test/components/edit-chrome/responsive-field-state.test.tsx` so vitest
#     (`npm run test:components`) actually runs it.
#
# RULES FOR ADDING AN ENTRY
#   1. One path per line, exactly as printed relative to `web/` (e.g.
#      `src/lib/site-admin/foo.test.ts`). Matched by exact string equality —
#      not a glob, not a substring.
#   2. Every entry needs a comment saying WHY, plus the follow-up that will
#      remove it. A quarantine is a dated loan, not a resting place.
#   3. NEVER quarantine a test that surfaced a real product bug — fix the bug.
#      Quarantine is for runner mismatches and stale fixtures only.
